# 好好理財｜財務日記

個人財務網站，分類管理日常開銷、娃娃機、台股投資與夢想旅遊基金。資料儲存在目前瀏覽器，無需註冊。

## 本機啟動

需安裝 Python 3。在專案資料夾執行 `python server.py`（或 `npm start`），再開啟本機服務網址（預設連接埠 8000）。本機 Python 服務提供靜態網站與 `/api/quote?symbol=2330` 台股報價端點。

## 功能

- 月份總覽；日常收入／日常開銷各自統計，娃娃機營收獨立統計
- 娃娃機娃娃、零食、場租、其他成本、機台營收細項統計，並可新增自訂細項
- 台股代號市價與市場更新時間，持倉股數、平均成本、市值、未實現損益與已實現損益；全部以新台幣計價
- 每筆股票買賣可記錄成交股數、成交單價、手續費及證交稅；手續費與稅費納入平均成本及已實現損益
- 報價無法取得時可手動輸入現價，並記錄更新時間
- 旅遊基金目標、存入／提領及進度追蹤
- 收支分類篩選、刪除、JSON 匯出與還原

台股報價由本機 Python 服務查詢 Yahoo 奇摩股市個股頁（上市 `.TW`、上櫃 `.TWO`）；如頁面欄位變動，會改以 Yahoo 報價資料備援。上游服務可能延遲或限制查詢，無法取得時可手動輸入現價。價格僅供個人記帳參考。

資料只儲存在這個瀏覽器與裝置。清除瀏覽器網站資料前，請先匯出 JSON 備份。部署到雲端靜態空間時不會包含本機報價代理，請在本機使用報價功能或手動輸入現價。Firestore 規則拒絕所有存取。
